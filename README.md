# Engineering Lab

A long-running engineering workspace for exploring software development through experiments, prototypes, algorithms, and practical implementation...

This repository contains work accumulated over time while exploring different areas of software engineering. Some projects are small and focused on a single concept, while others grow into more complete experiments or application prototypes...

The purpose of this repository is not to present a collection of finished products. It is a place to test ideas, investigate technologies, solve problems, and keep track of how different approaches evolve over time.

## What You'll Find Here

The repository covers a range of topics and technologies, including:

* Algorithms and problem solving
* Python development
* JavaScript development
* Frontend experiments
* Backend development
* Django and web application concepts
* API and server-side work
* Testing and debugging
* Data processing
* Mathematical and logic-based problems
* Small application prototypes
* Experiments with new tools and technologies

The contents change over time as new ideas are explored and existing experiments are revisited.

## Engineering Areas

### Algorithms & Problem Solving

A collection of algorithmic problems, mathematical exercises, data processing tasks, and different approaches to solving programming problems.

The focus is on understanding the problem, comparing possible solutions, and improving implementation rather than simply collecting completed exercises.

### Python

Python experiments covering language features, algorithms, backend concepts, automation, data processing, and smaller application ideas.

### JavaScript

JavaScript work ranging from language experiments and algorithms to browser-based functionality and application logic.

### Backend

Experiments with server-side development, Django, APIs, application structure, and backend-related concepts.

Some of these experiments are intentionally small and isolated, while others are used as the starting point for larger projects.

### Frontend

Interface experiments, browser functionality, HTML/CSS work, JavaScript interactions, and smaller UI implementations.

### Experiments & Prototypes

Ideas that are being tested before becoming independent projects.

This includes temporary implementations, proof-of-concept work, technology experiments, and early versions of ideas that may later evolve into standalone applications.

## How This Repository Evolves

This is an active, long-term repository.

Some directories remain small because the original idea was only intended as an experiment. Others have continued to evolve as new requirements, technologies, or implementation approaches were explored.

Older work is intentionally kept here as part of the development history rather than being replaced whenever a newer approach is discovered.

This makes the repository useful not only as a workspace, but also as a record of different engineering decisions and approaches over time.

## Selected Work

Some experiments eventually become independent projects with their own repositories, documentation, and deployment.

When an idea develops beyond the scope of this workspace, it is separated into a dedicated project rather than keeping everything inside this repository.

This repository therefore acts as the starting point for many smaller ideas and technical experiments.

## Philosophy

The goal is simple: build, test, understand, improve, and repeat.

Not every experiment needs to become a product. Some are created to understand a particular concept, some to test an implementation, and others eventually become larger projects.

Keeping these experiments together makes it easier to explore ideas without forcing every piece of work into the structure of a finished application.

## Status

Continuously evolving.

New experiments, implementations, and technical work are added as development continues.
